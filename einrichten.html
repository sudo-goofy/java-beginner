Die Entwicklungsumgebung

Acht Handgriffe, mit denen du jedes Programm in diesem Skript zum Laufen bringst, in VS Code und in IntelliJ IDEA, jeweils nebeneinander.

2 Programme einmal einrichten, dann nachschlagen

Auf dieser Seite

Die eine Regel

Eine IDE (integrierte Entwicklungsumgebung) vereint Editor, Compiler-Aufruf und Fehlersuche unter einer Oberfläche. Java selbst, das JDK, steckt nicht darin, sondern kommt dazu. Und: Der Code, den du schreibst, ist in beiden Programmen Zeichen für Zeichen derselbe. Was sich unterscheidet, sind acht Handgriffe. Die stehen hier.

Nimm die, die auf deinem Rechner läuft, und dann nimm sie ein halbes Jahr lang. Das Umsteigen kostet einen Nachmittag, den Umstieg bereust du in Woche drei, und deine Klasse hat sich sowieso schon entschieden.

Welche nehme ich?

Beide sind kostenlos, beide laufen unter Windows, macOS und Linux, und mit beiden kommst du durch dieses Skript. Es gibt keine falsche Wahl, nur eine, die du triffst, und eine, die du vor dir herschiebst.

Visual Studio Code

Startet schnell, läuft auch auf schwachen Rechnern und kann später jede andere Sprache mit.

Haken: Java kann es nicht von Haus aus, erst die Erweiterung macht daraus eine Java-Umgebung.

Herkunft: code.visualstudio.com

IntelliJ IDEA

Ist auf Java gebaut: Sie versteht deinen Code besser als jede andere und schlägt oft die Lösung vor, bevor du den Fehler siehst.

Haken: Braucht mehr Arbeitsspeicher und zeigt beim ersten Start sehr viele Knöpfe auf einmal.

Herkunft: jetbrains.com/idea

Falls dir jemand „Community Edition“ gesagt hat

Von IntelliJ IDEA gab es jahrelang zwei getrennte Downloads: die kostenlose Community Edition und die kostenpflichtige Ultimate. Seit Ende 2025 gibt es nur noch einen Download. Ohne Bezahlung bekommst du darin genau das, was früher Community hieß, und das reicht für alles in diesem Skript und weit darüber hinaus. Du suchst also nicht mehr nach der Community Edition, sondern lädst schlicht IntelliJ IDEA herunter.

Wer an einer Schule lernt oder unterrichtet, bekommt auf Antrag zusätzlich die Ultimate-Funktionen kostenlos. Nötig ist das für Lernfeld 5 nicht.

Und was war mit Eclipse?

Eclipse war zwanzig Jahre lang die Java-Umgebung, und an vielen Schulen steht sie noch. Du kannst damit jede Aufgabe hier lösen, die Handgriffe heißen nur anders. Wir zeigen die beiden, die du im Betrieb am wahrscheinlichsten antriffst.

Die acht Handgriffe

Der Reihe nach: Die ersten vier brauchst du einmal, die letzten vier immer wieder. Such dir oben dein Programm aus, die Seite merkt sich die Wahl.

Alles finden, ohne zu suchen

Der wichtigste Handgriff, und der einzige, den du wirklich auswendig können musst. Beide Programme haben eine Zeile, in die du tippst, was du willst, statt es in Menüs zu suchen. Alle folgenden Handgriffe gehen darüber.

VS Code

  1. Strg + Umschalt + P öffnet die Befehlspalette.
  2. Tipp los, was du vorhast, etwa Java: für alles, was mit Java zu tun hat.
  3. Rechts neben jedem Befehl steht sein Tastenkürzel. So lernst du sie nebenbei.

IntelliJ IDEA

  1. Zweimal Umschalt öffnet Überall suchen: Dateien, Klassen, Aktionen, alles.
  2. Strg + Umschalt + A sucht gezielt nur Aktionen, also Befehle.
  3. Rechts neben jeder Aktion steht ihr Tastenkürzel. So lernst du sie nebenbei.

Java selbst besorgen

Die IDE bringt Java nicht mit. Java, genauer das JDK mit Compiler und JVM, holst du einmal dazu. Version 21 oder neuer, alles darunter ist zu alt.

VS Code

  1. VS Code bringt kein Java mit. Erst die Erweiterung Extension Pack for Java von Microsoft installieren, sie enthält alles, was du brauchst.
  2. Dann in der Befehlspalette: Java: Install New JDK. Das lädt eins herunter.
  3. Nachsehen, was gerade benutzt wird: Java: Configure Java Runtime.

IntelliJ IDEA

  1. IntelliJ bringt kein Java mit, holt es aber selbst.
  2. Beim Anlegen eines Projekts steht im Feld JDK ganz unten Download JDK. Eine Version aussuchen, klicken, warten.
  3. Später ändern: File → Project Structure → Project → SDK.

Ein Projekt anlegen

Ein Projekt ist nur ein Ordner mit Ansage: Hier drin liegt Java-Code, und zwar in src. Für dieses Skript reicht eins, etwa mit dem Namen ZombieApocalypse: Darin bekommt jedes Programm seine eigene Klasse.

VS Code

  1. Befehlspalette: Java: Create Java Project.
  2. Als Bauwerkzeug No build tools wählen. Maven und Gradle kommen später im Beruf, jetzt wären sie nur im Weg.
  3. Ordner aussuchen, Name ZombieApocalypse. VS Code legt src gleich mit an.

IntelliJ IDEA

  1. File → New → Project, links Java auswählen.
  2. Als Build system die Einstellung IntelliJ lassen, Maven und Gradle kommen später im Beruf.
  3. Name ZombieApocalypse, JDK auswählen, anlegen. Der Code gehört in src.

Eine Klasse anlegen

Jede Klasse steht in ihrer eigenen Datei, und die Datei heißt exakt wie die Klasse, Zombie also in Zombie.java. Sonst meldet der Compiler einen Fehler; die Meldung dazu steht im Panik-Wörterbuch.

VS Code

  1. Rechtsklick auf den Ordner src, dann New File.
  2. Name mit Endung eintippen: Zombie.java. Die Endung vergisst man genau einmal.
  3. In der leeren Datei class tippen und Tab drücken, die IDE ergänzt das Gerüst.

IntelliJ IDEA

  1. Rechtsklick auf den Ordner src, dann New → Java Class.
  2. Name ohne Endung eintippen: Zombie. Die Datei legt IntelliJ passend an.
  3. Im Klassenrumpf main tippen und Tab drücken, die IDE ergänzt die main-Methode.

Das Programm starten

Beide IDEs erkennen die main-Methode und bieten den Start direkt daneben an. Du musst nichts einstellen.

VS Code

  1. Über der Zeile mit main steht klein Run | Debug. Auf Run klicken.
  2. Oder Strg + F5: startet ohne Debugger, das ist der Normalfall.
  3. Die Ausgabe erscheint unten im Terminal.

IntelliJ IDEA

  1. Links neben der Zeile mit main steht ein grünes Dreieck. Draufklicken, Run wählen.
  2. Oder Umschalt + F10: startet noch einmal, was zuletzt lief.
  3. Die Ausgabe erscheint unten im Run-Fenster.

Eine Endlosschleife stoppen

Kommt vor. Kommt bei allen vor. Wichtig ist nur, dass du den roten Knopf findest, bevor der Lüfter aufgibt.

VS Code

  1. Im Terminal unten das rote Quadrat anklicken.
  2. Oder ins Terminal klicken und Strg + C drücken.

IntelliJ IDEA

  1. Im Run-Fenster unten das rote Quadrat anklicken.
  2. Oder Strg + F2 drücken.

Klasse und Datei zusammen umbenennen

Von Hand umbenennen geht schief: Entweder passt der Klassenname nicht mehr zum Dateinamen, oder irgendwo steht noch der alte. Beide IDEs machen es in einem Zug, überall, auch in Dateien, die gerade zu sind.

VS Code

  1. Den Cursor in den Klassennamen setzen.
  2. F2 drücken, neuen Namen tippen, Enter.
  3. Die Datei wird mitbenannt, und jede Stelle, die die Klasse benutzt, auch.

IntelliJ IDEA

  1. Den Cursor in den Klassennamen setzen.
  2. Umschalt + F6 drücken, neuen Namen tippen, Enter.
  3. Die Datei wird mitbenannt, und jede Stelle, die die Klasse benutzt, auch.

Fehler sehen, bevor du startest

Der Compiler meldet sich sowieso, aber die IDE meldet sich früher, nämlich beim Tippen. Die rote Wellenlinie ist derselbe Fehler, nur zehn Sekunden eher.

VS Code

  1. Rote Wellenlinie im Code: mit der Maus darüber, dann steht die Meldung da.
  2. Alle Fehler auf einmal: Strg + Umschalt + M öffnet Probleme.
  3. Die Zahl unten links in der Leiste zählt mit.

IntelliJ IDEA

  1. Rote Wellenlinie im Code: mit der Maus darüber, dann steht die Meldung da.
  2. Der schmale Streifen rechts am Fensterrand zeigt jeden Fehler als Strich, draufklicken springt hin.
  3. Ein Häkchen oben rechts heißt: nichts zu beanstanden.

Warum hier fast keine Klickwege stehen

Ein Lehrskript, das „Klicke oben links auf das dritte Symbol“ sagt, ist beim nächsten Update falsch, und Updates kommen mehrmals im Jahr. Deshalb steht oben überall, wo es geht, ein Befehlsname oder ein Tastenkürzel statt eines Weges durch Menüs.

Das ist kein Trick fürs Skript, sondern der Handgriff, den erfahrene Leute tatsächlich benutzen. Wer Strg + Umschalt + P beziehungsweise zweimal Umschalt kann, findet auch in der Version von übermorgen alles wieder, und nebenbei auf jedem fremden Rechner.

Merk dir das

Nenne den Befehl, nicht den Klickweg. Menüs werden umgeräumt, Befehlsnamen bleiben.

Stand der Angaben: September 2026. Die Tastenkürzel gelten für Windows und Linux; unter macOS nimmst du statt Strg meist die Befehlstaste (⌘). Überall gleich funktioniert die Befehlssuche, in der du den Befehl eintippst.
