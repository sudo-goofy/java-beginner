The IDE

Eight procedures that get every program in this course running, in VS Code and in IntelliJ IDEA, each shown side by side.

2 programs set up once, then look things up

On this page

The one rule

An IDE (integrated development environment) combines editor, compiler call and debugging in one interface. Java itself, the JDK, is not part of it but comes on top. And: the code you write is the same, character for character, in both programs. What differs are eight procedures. They are listed here.

Pick the one that runs on your computer, and then use it for half a year. Switching costs an afternoon, you will regret the switch in week three, and your class has already decided anyway.

Which one should I pick?

Both are free, both run on Windows, macOS and Linux, and either one will get you through this course. There is no wrong choice, only the one you make and the one you keep putting off.

Visual Studio Code

Starts fast, runs on weak computers too, and can handle any other language later.

Catch: It can’t do Java out of the box; only the extension turns it into a Java environment.

Source: code.visualstudio.com

IntelliJ IDEA

Built around Java: it understands your code better than any other and often suggests the solution before you even see the error.

Catch: Needs more memory and shows a great many buttons at once on first start.

Source: jetbrains.com/idea

In case someone told you “Community Edition”

For years, IntelliJ IDEA came as two separate downloads: the free Community Edition and the paid Ultimate. Since late 2025 there is only one download. Without paying, you get exactly what used to be called Community, and that is enough for everything in this course and far beyond. So you no longer search for the Community Edition, you simply download IntelliJ IDEA.

If you learn or teach at a school, you can apply to get the Ultimate features for free as well. You don’t need them for Learning Field 5.

And what about Eclipse?

For twenty years, Eclipse was the Java environment, and at many schools it is still installed. You can solve every exercise here with it, the procedures just have different names. We show the two you are most likely to meet on the job.

The eight procedures

In order: you need the first four once, the last four again and again. Pick your program above; the page remembers your choice.

Find everything without searching

The most important procedure, and the only one you really have to know by heart. Both programs have a line where you type what you want instead of hunting for it in menus. All of the following procedures work through it.

VS Code

  1. Ctrl + Shift + P opens the Command Palette.
  2. Start typing what you want to do, for example Java: for everything to do with Java.
  3. To the right of each command is its keyboard shortcut. That’s how you learn them along the way.

IntelliJ IDEA

  1. Pressing Shift twice opens Search Everywhere: files, classes, actions, everything.
  2. Ctrl + Shift + A searches only actions, that is, commands.
  3. To the right of each action is its keyboard shortcut. That’s how you learn them along the way.

Getting Java itself

The IDE does not include Java. You get Java, more precisely the JDK with compiler and JVM, once, separately. Version 21 or newer; anything older is too old.

VS Code

  1. VS Code does not include Java. First install the Extension Pack for Java from Microsoft, which contains everything you need.
  2. Then, in the Command Palette: Java: Install New JDK. That downloads one.
  3. Check what is currently in use: Java: Configure Java Runtime.

IntelliJ IDEA

  1. IntelliJ doesn’t include Java either, but it fetches it itself.
  2. When you create a project, the JDK field has Download JDK at the very bottom. Pick a version, click, wait.
  3. Change it later: File → Project Structure → Project → SDK.

Create a project

A project is just a folder with a label: Java code lives in here, namely in src. For this guide, one is enough, for example named ZombieApocalypse: in it, every program gets its own class.

VS Code

  1. Command palette: Java: Create Java Project.
  2. Choose No build tools as the build tool. Maven and Gradle come later on the job, right now they would only be in the way.
  3. Pick a folder, name it ZombieApocalypse. VS Code creates src for you right away.

IntelliJ IDEA

  1. File → New → Project, select Java on the left.
  2. Leave the Build system setting at IntelliJ; Maven and Gradle come later on the job.
  3. Name it ZombieApocalypse, select a JDK, create the project. The code belongs in src.

Create a class

Every class lives in its own file, and the file is named exactly like the class: Zombie goes in Zombie.java. Otherwise the compiler reports an error; the message is in the Panic glossary.

VS Code

  1. Right-click the src folder, then New File.
  2. Type the name with the extension: Zombie.java. You forget the extension exactly once.
  3. In the empty file, type class and press Tab; the IDE fills in the skeleton.

IntelliJ IDEA

  1. Right-click the src folder, then New → Java Class.
  2. Type the name without the extension: Zombie. IntelliJ creates the matching file.
  3. In the class body, type main and press Tab; the IDE fills in the main method.

Running the program

Both IDEs recognize the main method and offer to run it right next to it. You don’t have to configure anything.

VS Code

  1. Above the line with main you will see a small Run | Debug. Click Run.
  2. Or Ctrl + F5: runs without the debugger, which is the normal case.
  3. The output appears at the bottom in the Terminal.

IntelliJ IDEA

  1. To the left of the line with main there is a green triangle. Click it and choose Run.
  2. Or Shift + F10: runs again whatever ran last.
  3. The output appears at the bottom in the Run window.

Stopping an infinite loop

It happens. It happens to everyone. All that matters is that you find the red button before the fan gives up.

VS Code

  1. In the Terminal at the bottom, click the red square.
  2. Or click into the terminal and press Ctrl + C.

IntelliJ IDEA

  1. In the Run window at the bottom, click the red square.
  2. Or press Ctrl + F2.

Renaming class and file together

Renaming by hand goes wrong: either the class name no longer matches the file name, or the old name is still used somewhere. Both IDEs do it in one go, everywhere, even in files that are currently closed.

VS Code

  1. Put the cursor in the class name.
  2. Press F2, type the new name, Enter.
  3. The file is renamed too, and so is every place that uses the class.

IntelliJ IDEA

  1. Put the cursor in the class name.
  2. Press Shift + F6, type the new name, Enter.
  3. The file is renamed too, and so is every place that uses the class.

Seeing errors before you run

The compiler will report them anyway, but the IDE reports them earlier, namely while you type. The red squiggly line is the same error, just ten seconds sooner.

VS Code

  1. Red squiggly line in the code: hover over it with the mouse and the message appears.
  2. All errors at once: Ctrl + Shift + M opens Problems.
  3. The number at the bottom left of the bar keeps count.

IntelliJ IDEA

  1. Red squiggly line in the code: hover over it with the mouse and the message appears.
  2. The narrow strip at the right edge of the window shows every error as a tick mark; click it to jump there.
  3. A check mark at the top right means: nothing to complain about.

Why there are almost no click paths here

A course handout that says “Click the third icon at the top left” is wrong after the next update, and updates come several times a year. That is why, above, wherever possible, you will find a command name or a keyboard shortcut instead of a path through menus.

That is not a trick for this course, but the procedure experienced people actually use. Once you know Ctrl + Shift + P or Shift twice, you will find everything again in any future version, and on any stranger’s computer as well.

Remember this

Name the command, not the click path. Menus get rearranged, command names stay.

Information current as of: September 2026. The keyboard shortcuts apply to Windows and Linux; on macOS you usually use the Command key (⌘) instead of Ctrl. Command search, where you type the command, works the same everywhere.
